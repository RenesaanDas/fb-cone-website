# 📘 Facebook Clone Website

A Facebook-inspired website developed as part of my Git and GitHub learning journey. This project was created during our Git tutorial to gain practical experience in web development while understanding the fundamentals of version control and collaborative coding.

The main purpose of this project was to practice managing code changes, tracking project progress, working with Git commands, and understanding how developers use GitHub to manage and maintain their projects.

---

## 🌐 About the Project

This project is a clone of the Facebook website interface. It was developed for educational and practice purposes to understand the structure and design of a real-world social media platform.

While building this project, I explored how a website project is organized and how Git helps developers maintain different versions of their code.

This project represents one of my initial steps toward learning professional software development workflows.

## 🎯 Project Objectives

- To understand the fundamentals of Git and GitHub.
- To learn how to initialize and manage a Git repository.
- To understand how version control works in real-world projects.
- To practice staging, committing, and tracking code changes.
- To learn how to create and manage different branches.
- To understand merging and branch management.
- To gain practical experience with Git commands.
- To become familiar with managing projects through GitHub.

## 🛠️ Technologies Used

The following technologies were used in this project:

- **HTML5** – To create the structure of the website.
- **CSS3** – To style the website and design its layout.
- **Git** – To track changes and manage version history.
- **GitHub** – To host and manage the project repository.

## 📚 Git Concepts Practiced

During this project, I practiced several important Git and GitHub concepts:

| Git Command | Purpose |
|---|---|
| `git init` | Initializes a new Git repository. |
| `git status` | Checks the current status of files. |
| `git add .` | Adds changes to the staging area. |
| `git commit -m "message"` | Saves changes with a commit message. |
| `git log` | Displays the commit history. |
| `git branch` | Lists available branches. |
| `git checkout` | Switches between branches. |
| `git switch` | Switches to another branch. |
| `git merge` | Combines changes from different branches. |
| `git push` | Uploads local commits to GitHub. |
| `git pull` | Fetches and integrates remote changes. |
| `git clone` | Copies a remote repository to a local machine. |
